# HIPAA and NIST SP 800-207 Control Mapping

## Project Overview
This document provides an illustrative mapping between Zero Trust Architecture principles, NIST SP 800-207, and the HIPAA Security Rule.

## Security Control Mapping

| Zero Trust Principle | HIPAA Security Rule Reference | Implementation Example |
|---|---|---|
| Identity verification | 45 CFR § 164.312(d) | Verify workforce identity before EHR access |
| Least-privilege access | 45 CFR § 164.312(a)(1) | Role-based access to patient records |
| Audit logging | 45 CFR § 164.312(b) | Monitor and log EHR access events |
| Transmission protection | 45 CFR § 164.312(e)(1) | Protect PHI transmitted between systems |
| Device and network segmentation | 45 CFR § 164.308(a)(1)(ii)(B) | Risk-based isolation of medical devices |
| Incident response | 45 CFR § 164.308(a)(6) | Investigate and respond to cybersecurity incidents |

## Important Note
NIST SP 800-207 provides architectural guidance rather than a prescriptive HIPAA compliance checklist. These mappings are illustrative and do not by themselves demonstrate regulatory compliance.
